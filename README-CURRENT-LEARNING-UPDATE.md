# VICO Dashboard — Current Learning Card

Updated the Dashboard card from “What you'll learn” to “What you're learning now”. It identifies the student's current Foundation 1 chapter, current learning point, and provides a Continue Chapter 1 action.

The exact lesson point is not fabricated: until lesson progress is persisted, the card says “Start at the beginning of this chapter” and explains that the exact point will update when progress is saved.

Run from `student/`:

```powershell
npm install
npm run dev
```
