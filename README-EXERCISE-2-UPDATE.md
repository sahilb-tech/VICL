# VICO Foundation 1 — Exercise 2 integration

- Added the uploaded interactive quiz at `student/public/exercises/exercise2/index.html`.
- Added the Exercise 2 card to the Student Exercises list.
- Added routes `/student/exercises/2` and `/student/exercises/chapter/2`.
- The quiz retains its original questions, answer checking, progress bar, feedback, and final score. The final score is displayed inside the Exercise 2 page, not in Results & Progress.

## Run locally
1. Open a terminal in `student`.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start Vite.
4. Open the local URL printed by Vite, sign in, and choose **Exercises → Exercise 2**.
