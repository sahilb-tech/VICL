# VICO Foundation 1 — Chapter Topic Progress

Updated the student My Learning page with an individual progress bar and topic checklist under each of the nine Foundation 1 chapters.

## Behaviour
- Each chapter displays its own topic completion count and green progress bar.
- Students can click a learning point to mark it as read; completed points show a green tick.
- Topic completion is saved in browser localStorage.
- Completing every starter topic in a chapter marks that chapter complete in the overall Foundation 1 progress calculation.
- Progress updates on the Dashboard and My Learning page during the current browser session.

## Important curriculum note
The topic labels are starter learning points based on the chapter names and the examples supplied. They are not verified transcriptions of the textbook. Compare them with the authorized Foundation 1 PDF and update the labels before using this as the final textbook-aligned curriculum.

## Run the student app
From the `student` directory:

```powershell
npm install
npm run dev
```
