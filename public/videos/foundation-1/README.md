# VICL Foundation 1 chapter videos

The subtitled Chapter 1 video is bundled as `chapter-1.mp4` and is connected to the Chapter 1 player.

To enable the other chapter players, copy the final MP4 exports into this folder using these names:
- `chapter-2.mp4` — Applications of Computers
- `chapter-3.mp4` — Keyboard and Mouse
- `chapter-4.mp4` — Parts of a Computer
- `chapter-5.mp4` — IPO Cycle
- `chapter-6.mp4` — Fun with Tux Paint
- `chapter-7.mp4` — Sequencing and Decoding
- `chapter-8.mp4` — Instructions and Direction Sense
- `chapter-9.mp4` — AI and Robotics

Then update `videoPath` in `src/pages/StudentPortal.jsx` to map each chapter number to its matching file. Only the Chapter 1 MP4 was available in the working files when this package was prepared, so the remaining chapters show the designed player placeholder until their video files are added.
